# Gefina

Sistema para gestão de contas a receber.

O Gefina registra os clientes de uma organização e as faturas emitidas contra esses clientes, e apresenta a visão consolidada da situação financeira que desses rgistros decorre

## Funcionalidade

-Cadastro e manutenção de clientes
-Emissão e manutenção de faturas
-Listagens com busca, orientação e paginação
-Painel de indicadores consolidados
-Acesso autenticado e administração de contas

## Fora do escopo

-Cadastro público de usuários
-Recuperação de senha
-Envio de arquivo de imagem
-Representação gráfica de séries temporais
